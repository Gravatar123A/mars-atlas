Every source in view.

This register lists the public scientific data, image layers, mission records, code libraries, fonts, and services used to make Mars Atlas. NASA observations, USGS processing, ESA inputs, and our own calculations are identified separately.

How to read the map

Orbital images are visual context. Routes, slope, ascent, distance, and travel estimates are calculated by Mars Atlas from the listed numerical terrain products and user settings. They are not NASA measured routes. The Gale DEM also includes ESA Mars Express HRSC input and USGS processing. Gusev has imagery and a documented landing point but no packaged numeric route grid.

Source GeoTIFFs are not embedded in the website. The app serves sampled, checksum checked terrain packages derived from them. Full extraction steps, source hashes where available, and metric definitions are in the data source notes and scientific method.

Use and rights

The site uses published NASA imagery and USGS terrain for educational and informational research, with source acknowledgement and no agency insignia or endorsement. NASA media guidance and USGS credit guidance are linked above. The Gale composite includes upstream ESA Mars Express data; no standalone ESA image is republished. Lucide icons retain their ISC license in the public icon directory. The user-provided style reference is not republished.

Authorship and SI disclosure

OpenAI Codex assisted with code, interface copy, documentation, and presentation creation. Project members directed, reviewed, and tested the work. No SI generated image, video, or audio is used on this site or in the demo. Demo screenshots show the running app and are annotated with editable circles. No NASA logo or mission insignia is used.

The site's product layout and visual system were developed for Mars Atlas; a user provided dashboard image served only as visual direction and is not published as an asset. Route results are software generated from cited measured data and are identified as derived calculations. Icons are from Lucide under its ISC license.
