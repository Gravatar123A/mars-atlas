The terrain label documents an equirectangular, planetocentric, east-positive Mars projection with a 3,396.19 km sphere. The UI uses that radius for distances. The cropped grid covers about 77.35–77.51°E and 18.42–18.50°N; coverage outside it is unknown to the routing model.

The source GeoTIFF retrieved on October 17 had SHA-256 `16a1aa66c3f48c1bca252795827db7b417876217aff0f5e1aff18027fab2327b`. The extraction script records this hash in `jezero-grid.json` so a future rebuild can confirm it used the same source object. The crop contains 475 × 238 finite elevation cells.

Mars Trek capabilities and sample tiles for CTX, HiRISE, and THEMIS responded on October 17. Tile services remain external and may fail independently of the cached numeric DEM. The source file's acquisition dates, individual input stereo observations, vertical uncertainty, and redistribution terms need deeper product-level review before a scientific publication or operational use.
